## Scale

### Curriculum / learner layer
- **CORE** — directly supported by current KNTT S1 as required knowledge/method.
- **CORE_SUPPORT** — S1-supported or strongly adjacent support, useful for depth/remediation, but should not become a silent gate.
- **ENTRANCE10** — exam-transfer / advanced extension beyond the minimum routine form.
- **SPECIALIZED_CHALLENGE** — high-extension material; never required for Core.

### Pedagogical value
- **H** — strong conceptual/method transfer value.
- **M** — useful support/variation.
- **L** — low incremental value if already represented by another family.

### Written requirement
- **YES** — learner should complete at least one full written response/rubric example.
- **PARTIAL** — interactive practice is useful, but at least one worked/written example is desirable.
- **NO** — can be adequately introduced/checked in concise interactive form.

## What the matrix says about CT09 content priorities

### Priority A — must be deep and clear

1. meaning of equation/system and graphical intersection;
2. substitution and elimination with method-selection reasoning;
3. transforming equations before solving;
4. full written two-unknown modeling;
5. checking conditions and interpreting the result.

### Priority B — enough variation to support transfer

- fractional/decimal/irrational coefficients;
- solution-count structures;
- mixture, motion, work, budget/cost contexts;
- coefficient/parameter-lite official S1 tasks.

### Priority C — Entrance10 bridge

- repeated-expression substitution before solving a system;
- full parameter biện luận;
- positive/integer constraints;
- harder modeling where the two relationships are not obvious.

### Priority D — optional challenge

- three-variable/symmetric/Diophantine systems;
- specialized optimization tied to line/system structure.

## Anti-inflation decisions

The following do **not** create new problem types:
- changing coefficients only;
- changing product names, ticket names, flower names or units while preserving the same equations;
- swapping substitution and elimination when either method is trivial and no method-choice lesson is being taught;
- adding a parameter symbol when the learner merely substitutes a provided numerical value.

A new variant is justified only when it changes:
- recognition;
- method selection;
- domain/condition handling;
- modeling structure;
- error risk;
- reasoning depth.

## Provisional content-design consequence

For a self-learning CT09 module, a smaller set of well-chosen anchors is preferable to a large cloned bank.

A candidate balanced design should eventually include:
- concise Core theory and graphical meaning;
- worked substitution/elimination examples with method choice;
