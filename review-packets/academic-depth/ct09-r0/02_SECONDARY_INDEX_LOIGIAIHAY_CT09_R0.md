## 4. Quality-control finding

The same generic page contains an important warning sign for source authority.

Its method note correctly states the standard condition for a linear equation in two variables: the two coefficients are not simultaneously zero. However, the detailed explanation immediately following the correct answer contains a contradictory sentence treating the zero-zero coefficient case as linear.

Therefore:
- the answer selection may still be correct;
- the explanatory text is not reliable enough to serve as S1 authority;
- all Loigiaihay solution text must be independently checked before reuse or pedagogical adoption.

This confirms the project classification:
- generic Loigiaihay sets → S2 exam-style/reference;
- named-school items → S3 candidate only after provenance verification;
- Loigiaihay explanations → secondary method reference, never curriculum authority.
