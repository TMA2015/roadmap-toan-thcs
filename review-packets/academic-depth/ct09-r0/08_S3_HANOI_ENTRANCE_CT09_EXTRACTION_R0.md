## 2. Current-program observations: 2025–2026

Sample size: **2 official Hà Nội entrance exams**.

This sample is too small for broad claims such as “always appears” or “dominant”, but it is strong enough to record exact observed structures.

### 2025

Relevant CT09 structure:

- Câu III.2 is a two-unknown price/discount modeling problem:
  - total listed price is given;
  - two different discount rates are applied;
  - total amount paid is given;
  - learner must determine the two original prices.

Canonical mathematical structure:
[
x+y=T,qquad r_1x+r_2y=P.
]

Role:
- **SYSTEM_MODELING_TWO_UNKNOWNS**
- authentic real-world context;
- requires unknown selection, equation formation, system solving and contextual conclusion.

Not observed as a standalone CT09 item:
- direct routine “solve this linear system” question.

### 2026

Relevant CT09 structure:

- Câu III.2 is a count-and-cost problem:
  - total number of flowers;
  - two flower types with different unit prices;
  - total cost;
  - determine number of each type.

Canonical structure:
[
x+y=N,qquad p_1x+p_2y=C.
]

Role:
- **SYSTEM_MODELING_TWO_UNKNOWNS**
- authentic count/value modeling;
- requires forming and solving a two-variable linear system.

Not observed as a standalone CT09 item:
- direct routine “solve this linear system” question.

### Current-program exact observations

Within the reviewed 2025–2026 sample:

- two-unknown linear-system modeling: **2/2 observed**;
- standalone direct system solving: **0/2 observed**;
- both system-modeling items are concrete real-world contexts with two independent relationships.

Interpretation guard:
- **2/2 is an observed count in a two-exam sample, not a claim of universal frequency.**
- It supports giving D4/D5 weight to system modeling and written equation formation.
- It does not justify removing direct procedural practice, because S1 explicitly requires the underlying solving methods.

## 3. Historical continuity observations: 2023–2024

These exams precede the current-program entrance format and are not pooled into current-frequency counts.

### 2023

Câu III.1 contains a transformed two-variable system of the form:
[
rac{2}{x-3}-3y=1,qquad rac{3}{x-3}+2y=8.
]

Role:
- **TRANSFORM_THEN_SOLVE_SYSTEM**
- learner recognizes a substitution such as (u=1/(x-3)) and solves a linear system.

The paper also contains a production-plan word problem under the instruction “lập phương trình hoặc hệ phương trình”, but its natural solution can be one-variable and is not counted as direct CT09 system evidence.

### 2024

Câu III.1 contains a system with a shared radical expression, structurally:
[
sqrt{3x+1}+2y=4,qquad 3sqrt{3x+1}-y=5.
]

Role:
- **TRANSFORM_THEN_SOLVE_SYSTEM**
- learner substitutes a common expression and solves the resulting linear system.

The paper also contains a truck-capacity word problem under “lập phương trình hoặc hệ phương trình”; it is retained as modeling context but not counted as pure system evidence without forcing a two-variable formulation.

### Historical continuity signal

Both 2023 and 2024 official papers contain a nontrivial transformed-system solving item.

Use:
- supports Entrance10 transfer practice;
- supports the need to teach recognition/transformation, not only integer-coefficient routine systems.

Do not use:
- as direct current-program frequency evidence.

## 4. Source-backed CT09 implications

### 4.1 Written system modeling is now high priority

S1 already contains system modeling. The two directly relevant current-program Hà Nội exams reviewed both include a two-unknown system-modeling task.

Therefore the CT09 learner path should contain first-class written practice for:
- selecting two unknowns;
- attaching conditions/units;
- translating two independent relationships;
- solving;
- checking;
- writing the contextual conclusion.

### 4.2 Direct solving remains foundational, but D5 treatment changes

Standalone direct system solving is not observed in the two current-program papers, while S1 still teaches substitution/elimination as required methods.

Therefore:
- direct solving remains **KNTT-Core / prerequisite**;
- its exam-authentic role should be described as a foundation enabling modeling and transfer;
- do not inflate the learner bank with many near-duplicate routine systems solely because they are easy to auto-grade.

### 4.3 Transfer/transformation deserves an Entrance10 bridge

Historical official exams show systems whose linear structure becomes visible after a substitution.

This supports a distinct Entrance10 family:
- **Recognize a repeated expression → substitute → solve linear system → back-substitute/check.**

This is structurally different from merely changing coefficients in a routine system.

### 4.4 Current-system modeling archetypes already evidenced

From 2025–2026:
- price/discount;
- count/value.

Combined with S1/SBT, candidate written archetypes can later include:
- count/value;
- price/discount;
- mixture/composition;
- motion/relative rate;
- work/rate;
- cost/revenue.

Only S3-observed archetypes may receive an authentic-exam-frequency count; S1/S2-only archetypes remain curriculum/pedagogical evidence.
