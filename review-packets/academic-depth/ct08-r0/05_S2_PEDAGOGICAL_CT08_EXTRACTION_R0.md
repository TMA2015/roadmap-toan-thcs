## 1. Equation-side pedagogical structures

The 2024 reference explicitly distinguishes:

### S2-EQ-01 — Basic product equation
Product form is already visible.

Pedagogical role:
- BASE / fluency.

### S2-EQ-02 — Transform to product form
Learner must recognize factorization or algebraic restructuring before applying zero-product.

Pedagogical role:
- METHOD / transfer.

### S2-EQ-03 — Repeated-expression / substitution extension
The reference includes a temporary-variable form under product-equation work.

Pedagogical role:
- useful extension/Entrance10 candidate;
- not automatically Core merely because the reference includes it.

### S2-EQ-04 — Rational equations
The reference treats equations with variable denominators as a distinct major theme.

Pedagogical role:
- domain first;
- equivalent transformation on the valid domain;
- candidate-root checking.

### S2-EQ-05 — Equation modeling
The reference separates solving word problems by setting up an equation.

Pedagogical role:
- model choice and contextual conclusion should be taught, not only final algebra.

## 3. First-degree inequality structures

The 2024 reference explicitly distinguishes:

Concept recognition.

### S2-INEQ-02 — Direct solve
Routine `ax+b square 0` work.

### S2-INEQ-04 — Practical application
Form an inequality from a constraint and interpret its solution in context.

## 4. Useful progression signal

Across the S1 + S2 evidence, a strong teaching progression emerges:

**recognize → direct solve → transform safely → trap/condition → model/interpret**

For CT08 specifically:

- product equation:
  direct product → factor/transform → optional substitution extension;
- rational equation:
  domain → clear denominator → solve → reject invalid candidate;
- order/inequality:
  verbal relation → order property → sign reversal contrast → transformed inequality → practical constraint;
- modeling:
  choose variable/units → form equation or inequality → solve → check context/discrete condition.

This progression is more useful for Academic Depth than simply counting current tags.
