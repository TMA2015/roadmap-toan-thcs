## Current Practice Bank structural concentration

Main bank:
- 132 questions;
- 17 top-level authored `tags.type` buckets;
- **0/132** stored static hints.

The absence of hints is not itself a defect under the project’s selective-hint policy.

However, several blocks are clearly numeric variants of one reasoning template:
- 12 × the same multi-step linear-equation skeleton;
- 8 × the same denominator-domain recognition skeleton;
- 12 × rational-equation blocks split into a few narrow patterns;
- 12 × product-equation items, mostly already factored;
- direct first-degree equation and inequality blocks repeat the same transformation with changed numbers.

A simple normalization pass over question strings yields many repeated clusters. This is diagnostic only; it is not a formal clone-family count.

### Anti-inflation conclusion

The current problem is **not too few questions**.

The likely remedy is:
1. preserve all 132 IDs/history;
2. classify structural variant groups;
3. improve session diversity;
4. add only a small number of questions for source-backed thin families such as PT08-05, PT08-11/PT08-13 if needed after review.
