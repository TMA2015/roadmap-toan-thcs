# Roadmap Site-wide Design System – UX pilot

## Scope
Global website shell + homepage + 25-topic library introduction. CĐ23 responsive lesson workspace is preserved without overrides to its functional selectors.

## Visual design
Learning portal, not document index: hero journey map, four route cards, three-step process, four subject cards, mobile layouts, dark-mode tokens and focus-preserving links.

## Non-regression
Do not mutate the question banks, attempts history, JavaScript storage keys or AI adapter. Validate 360px/mobile, iPad/tablet and desktop by owner device QA; PR build and syntax checks do not substitute for device QA.

## QA
PR workflow builds site strictly and checks content/Math/JS. New CĐ23 authored readiness still awaits separate academic review. Main branch and GitHub Pages intentionally unchanged until PR reviewed and merged.
