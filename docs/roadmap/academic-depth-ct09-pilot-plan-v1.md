# CT09 Academic Depth Pilot Plan v1 — Hệ phương trình

Date: 2026-10-03  
Status: **PILOT PLAN / NO CONTENT EDIT YET**

## 1. Why CT09

CT09 is the first deep pilot because it exercises all six audit dimensions:

- theory: equation/system meaning, geometry, equivalence, methods, number of solutions;
- worked examples: substitution, elimination, method choice, parameter, modeling;
- interactive practice: 120-item bank already exists;
- written problem solving: direct systems + word problems + Entrance10;
- exam relevance: strong connection to school assessment and grade-10 entrance preparation;
- help/remediation: many recognizable stuck points.

The purpose is to validate the **audit method**, not to assume CT09 is weak.

## 3. Pilot source corpus required

### S1 — Curriculum / textbook
Minimum:
- relevant Grade 9 KNTT textbook lesson(s);
- relevant KNTT workbook/exercise material when available;
- official curriculum/requirements needed to confirm the Core boundary.

Purpose:
- confirm exact Core scope;
- terminology;
- required methods;
- grade boundary;
- parameter/extension boundary.

### S2 — Pedagogical references
Target:
- 1–3 high-quality reference/advanced-practice sources covering systems of equations;
- preferably sources that explain problem types and methods, not only answer banks.

Purpose:
- identify classical methods and canonical examples;
- see useful intermediate problem types;
- compare progression from routine systems to written/modeling tasks.

Commercial sources are REFERENCE_ONLY by default.

### S3 — Authentic assessment
Initial target:
- recent Hanoi grade-10 entrance Math exams;
- a small selected set of semester/final exams from Hanoi schools with clear provenance;
- optionally selected official/traceable exams from other localities for comparison.

Purpose:
- identify actually observed forms;
- separate recurring structures from one-off variants;
- compare direct system solving vs system-as-tool in word problems;
- avoid unsupported “frequent in entrance exam” claims.

## 4. Initial problem-type hypotheses

These are **working hypotheses from current site structure**, not source-validated catalogue entries yet:

1. verify a pair as a solution;
2. interpret a system geometrically;
3. solve by substitution;
4. solve by elimination;
5. transform before solving;
6. rational/fractional coefficients that remain linear;
7. choose an efficient method;
8. determine number of solutions;
9. parameter with a prescribed solution;
10. parameter / conditions for number of solutions;
11. number/digit word problems;
12. rate/work/productivity problems;
13. motion problems;
14. other two-unknown real-world modeling;
15. cross-topic use with functions/graphs;
16. Entrance10 multistep modeling;
17. Challenge structure transformations.

The source audit may merge, split, remove or re-layer these.

## 5. Questions the pilot must answer

### Theory
- Is the current theory complete relative to S1?
- Is the geometric interpretation taught at the correct depth?
- Are equivalence operations explained sufficiently for self-study?
- Is the parameter section correctly outside Core where required?
- Are word-problem prerequisites explicit?

### Worked examples
- Do examples explain why substitution/elimination is selected?
- Is there a strong contrast example showing poor vs efficient method choice?
- Is there at least one canonical modeling example?
- Do examples include checking conditions/conclusions?

### Interactive practice
- Do 120 questions represent structural variety or many near-duplicates?
- Which problem types are overrepresented/underrepresented?
- Which interactive questions are trying to test written reasoning that MCQ cannot observe well?

### Written
- Are current written items genuinely complete self-study exercises or mostly short answer demonstrations?
- Do we have enough modeling and method-choice items?
- Do we have exam-style multistep items?
- Do solutions/rubrics teach the reasoning path?

### Exam coverage
- Which CT09 forms are actually observed in the selected Hanoi corpus?
- Which forms are standalone vs embedded in larger problems?
- Is the current “thi vào 10” section source-supported?

### Help/remediation
- Where is the learner likely to get stuck?
- Can the site provide small hint → method hint → partial step → full explanation?
- Is there a direct route back to prerequisites such as linear equations or algebraic manipulation?

## 7. No-edit rule before source audit

Until S1/S2/S3 evidence is assembled and the coverage matrix is built:

- do not add more CT09 questions just to increase count;
- do not delete existing questions based only on intuition;
- do not claim a type is frequent in Hanoi exams;
- do not move Core/Entrance10 boundaries without source evidence;
- do not change Mastery/Readiness.
