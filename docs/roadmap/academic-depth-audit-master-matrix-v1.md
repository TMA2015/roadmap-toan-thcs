## Required artifact per topic

Each completed topic audit must produce:

1. source inventory;
2. normalized problem-type catalogue;
3. coverage matrix;
4. six-dimension audit;
5. gap list with P0/P1/P2;
6. content delta plan;
7. independent review receipt when required;
8. integration receipt after learner-facing changes.

## First pilot recommendation

Start with **CT09 · Hệ phương trình** as the first deep pilot because it naturally exercises all six dimensions:

- core theory and method choice;
- worked examples;
- interactive practice;
- word-problem/modeling written work;
- strong relevance to school and entrance-10 style assessment;
- obvious need for hints/remediation when learners get stuck.

Do not mass-edit CT02–CT25 until the CT09 pilot proves the audit standard is practical.
