## Vai trò của lớp 8

Lớp 8 là đoạn mà nhiều mạch kiến thức bắt đầu kết nối thành chuỗi công cụ:

```text
đa thức
→ hằng đẳng thức
→ phân tích nhân tử
→ phân thức
→ phương trình
```

và:

```text
song song / tỉ lệ
→ Thalès
→ đồng dạng
→ Pythagore
→ hệ thức lượng
→ hình học tổng hợp
```

