# Tự kiểm tra – Chuyên đề 06: Phân tích đa thức thành nhân tử

> **Thời gian:** 40 phút  
> **Thang điểm:** 10 điểm

# Đề
1. **1 điểm:** Phân tích \(8x+16\).
2. **1 điểm:** Phân tích \(x^2-36\).
3. **1 điểm:** Phân tích \(x^2+8x+16\).
4. **1 điểm:** Phân tích \(5x^2-20x\).
5. **1,5 điểm:** Phân tích \(x^2-x-6\).
6. **1,5 điểm:** Phân tích \(ax-ay+bx-by\).
7. **1,5 điểm:** Phân tích \(x^3-9x\).
8. **1,5 điểm:** Giải \(x^2-9x+20=0\) bằng phân tích nhân tử.

# Đáp án
1. \(8(x+2)\).
2. \((x-6)(x+6)\).
3. \((x+4)^2\).
4. \(5x(x-4)\).
5. \((x-3)(x+2)\).
6. \((a+b)(x-y)\).
7. \(x(x-3)(x+3)\).
8. \(x=4\) hoặc \(x=5\).

**Mốc đạt:** 8/10; phải chọn đúng phương pháp thay vì thử khai triển dài.
