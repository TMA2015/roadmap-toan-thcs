# Bài tập – Chuyên đề 06: Phân tích đa thức thành nhân tử

> **Mục tiêu:** dùng đặt nhân tử chung, hằng đẳng thức, nhóm hạng tử và phối hợp phương pháp.
> **Quy ước:** `06-Mx-yy`.

# Mức 1 – Nhận biết
### 06-M1-01
Phân tích \(6x+12\).
### 06-M1-02
Phân tích \(x^2-25\).
### 06-M1-03
Phân tích \(x^2+6x+9\).

# Mức 2 – Thông hiểu
### 06-M2-01
Phân tích \(3x^2-12x\).
### 06-M2-02
Phân tích \(x^2-5x+6\).
### 06-M2-03
Phân tích \(ax+ay+bx+by\).

# Mức 3 – Vận dụng
### 06-M3-01
Phân tích \(x^3-4x\).
### 06-M3-02
Phân tích \(x^2+2xy+y^2-9\).
### 06-M3-03
Giải \(x^2-7x+12=0\) bằng phân tích nhân tử.

# Mức 4 – Tổng hợp
### 06-M4-01
Phân tích \(x^4-16\) hoàn toàn.
### 06-M4-02
Phân tích \(x^3+3x^2-4x-12\) bằng nhóm hạng tử.
### 06-M4-03
Tìm các số nguyên \(x\) để \(x^2-5x+6=0\) và giải thích liên hệ giữa nghiệm và các nhân tử.

# Đáp án nhanh
- 06-M1-01: \(6(x+2)\); 06-M1-02: \((x-5)(x+5)\); 06-M1-03: \((x+3)^2\).
- 06-M2-01: \(3x(x-4)\); 06-M2-02: \((x-2)(x-3)\); 06-M2-03: \((a+b)(x+y)\).
- 06-M3-01: \(x(x-2)(x+2)\); 06-M3-02: \((x+y-3)(x+y+3)\); 06-M3-03: \(x=3,4\).
- 06-M4-01: \((x-2)(x+2)(x^2+4)\); 06-M4-02: \((x+3)(x-2)(x+2)\); 06-M4-03: 2 và 3.
