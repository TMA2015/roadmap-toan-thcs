# Bài tập – Chuyên đề 06: Phân tích đa thức thành nhân tử

> **Mục tiêu:** luyện đặt nhân tử chung, dùng hằng đẳng thức, nhóm hạng tử và phối hợp nhiều phương pháp.

## Mức 1
1. Phân tích \(6x^2+9x\).
2. Phân tích \(x^2-16\).
3. Phân tích \(x^2+6x+9\).

## Mức 2
4. Phân tích \(ax+ay+bx+by\).
5. Phân tích \(x^2-5x+6\).
6. Phân tích \(2x^2-8\).

## Mức 3
7. Phân tích \(x^3-4x\).
8. Phân tích \(x^3+3x^2-4x-12\).
9. Giải phương trình \(x^2-7x+12=0\) bằng phân tích thành nhân tử.

## Đáp án nhanh
1. \(3x(2x+3)\).
2. \((x-4)(x+4)\).
3. \((x+3)^2\).
4. \((a+b)(x+y)\).
5. \((x-2)(x-3)\).
6. \(2(x-2)(x+2)\).
7. \(x(x-2)(x+2)\).
8. \((x+3)(x-2)(x+2)\).
9. \(x=3\) hoặc \(x=4\).
