- xác định Core knowledge;

- gắn PRIMARY / SECONDARY / PREREQUISITE;

- chỉ ra upstream prerequisites;
- chỉ ra downstream use;
- phát hiện gap / overreach / cross-link;
- nêu điểm cần lưu ý về sư phạm.

- Nếu không chắc, ghi UNCERTAIN.
