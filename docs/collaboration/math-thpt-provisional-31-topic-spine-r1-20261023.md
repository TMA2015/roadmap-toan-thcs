## 5. Ví dụ về các nhánh quan hệ tiên quyết (đề xuất, **chưa được audit item/skill-level**)

- **Lượng giác/hình học:** THCS tam giác đồng dạng, lượng giác vuông → HT16 → HT17 → HT18; HT16 → HT06 → HT07.
