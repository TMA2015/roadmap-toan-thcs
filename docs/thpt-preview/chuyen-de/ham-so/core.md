# Thẻ Core cũ — liên kết tương thích

Theo kiến trúc **Dual Complete Learning Paths v2**, Chuyên đề không còn mục Core riêng. Nội dung `THPT-CORE-QF01` chỉ được lưu **một nơi** tại [Thư viện Core SGK](../../sgk/core/ham-so-bac-hai.md).

Chuyên đề có ba phần: [Kiến thức](kien-thuc.md) · [Luyện tập](luyen-tap.md) · [Tự kiểm tra](tu-kiem-tra.md). Liên kết cũ này được giữ để không tạo trang lỗi; không có một bản câu hỏi Core trùng lặp ở đây.
