# Core theo bài SGK — Trang liên kết tương thích

**Core không còn là một mục riêng trong menu.** Học sinh truy cập Core từ bài SGK hoặc bảng Luyện tập/Vận dụng của chương. Trang này chỉ giữ các liên kết cũ hoạt động. Chọn Core theo lớp, chương, bài và kỹ năng. **Một item có một ID và một khóa đáp án canonical**. Với SGK, item này là Core; trong Chuyên đề nó có thể được tham chiếu ở Practice cơ bản, không cần mục Core riêng.
